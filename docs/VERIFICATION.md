# 验证记录

本文件记录发布前实际执行过的检查。所有结论都来自可重复的命令，不是主观描述。

## 构建

```
dotnet build src/PixelWorkspace/PixelWorkspace.csproj -c Release
dotnet build src/Launcher/Launcher.csproj -c Release
```

结果：0 警告、0 错误。win-x64 self-contained 发布成功（整理版与单文件版各一次）。

## 自检入口

```
app\PixelWorkspace.exe --self-test     # 算法层
app\PixelWorkspace.exe --smoke-test    # 界面层
```

结果：两者退出码 0，并在程序目录写出 `self-test.txt` / `smoke-test.txt`；smoke 报告主窗口与六个页面全部初始化成功。

`--self-test` 覆盖范围：

- **混淆**：13 组曲线坐标与原始 JavaScript 实现逐一对比（含 1×1、单行、单列、奇数与不对称尺寸）；13 组逐字节像素排列对比；13 组混淆 → 还原往返校验。
- **编辑**：裁剪源偏移、打码均值与透明度、高斯模糊冲激响应、旋转贴纸合成与命中测试、PNG 编码往返。
- **元数据**：注入文本字段的 PNG 重新编码后文本元数据为空；透明像素往返一致；输出不含 eXIf / tEXt / iTXt / zTXt 块。
- **视频播放条**：时长读取、播放推进、暂停冻结、拖动跳转、按键快进边界收敛。

## 手机查看（局域网服务）

用临时测试进程直接对内置 HTTP 服务发起请求：

| 检查 | 结果 |
| --- | --- |
| 不带口令访问 `/api/browse` | 401 |
| 正确口令登录 | 200 |
| 已登录 token 校验 | 200 |
| 退出登录后再次校验 | 401 |
| 重启服务后原 token 校验 | 200（设备授权持久化） |
| Range 请求 `bytes=100-199/1000` | 206 |
| 非法 Range | 416 |
| 不存在的文件 | 404 |
| 非图片请求缩略图 | 415 |
| `/index.html`、`/app.js`、`/styles.css`、`/manifest.json` | 200，Content-Type 正确 |
| 手机端 `/api/shutdown` | 200，随后监听端口关闭 |
| 共享目录边界（`..` 越界） | 拒绝 |
| 访问密码长度 | 16 位十六进制（8 随机字节 / 128 bit） |
| 连续 10 次错误口令 | 前 9 次 401，第 10 次 401 并提示已锁定 60 秒 |
| 锁定期间再尝试（含正确口令） | 429，提示剩余秒数 |
| 锁定结束后登录 | 200，失败计数清零 |

## 界面

- `--ui-preview` 在 900 / 1280 / 1380 三种宽度下渲染全部六个页面，按钮不重叠、不裁切。
- 播放条位于预览框下方，实测预览框底边 752、播放条顶边 775，无重叠。
- 进度条已播放段为主色青绿，未播放段为浅灰绿，渲染像素抽样确认已上色（1200+ 青绿像素）。

## 未覆盖

- 未做逐项真实鼠标操作的完整回归，也未做浏览器与 WPF 的像素级截图比对；原生控件与浏览器在字体度量、换行、间距上不保证一致。
- 系统保存对话框、与其他应用的剪贴板互通、完整 ZIP 用户操作链未人工逐一验收。
- JPEG 使用 Windows 编码器，不保证与其他编码器字节一致；色彩管理与半透明像素舍入也可能有差异。
- WebP 等格式取决于系统解码器；动图处理仅保留第一帧。
- 编辑器导入最长边限制 2500px；贴纸解码上限 10000px；撤销历史上限每图 24 状态或约 160MB。
- 部分笔刷与 ZIP 导出同步执行，大图/大批量时窗口可能短暂无响应。
- 视频缩略图对 mkv/webm 依赖系统缩略图处理程序。
