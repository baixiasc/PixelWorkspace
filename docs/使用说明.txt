像素工作台 · 使用说明

一、怎么启动
1. 解压整个文件夹，不要只挑其中的 exe。
2. 双击最外层的「像素工作台.exe」。
3. 如果 Windows 弹出「已保护你的电脑」，点「更多信息」→「仍要运行」。这是个人开发者未购买代码签名证书导致的提示。
4. 单文件版只有一个 exe，双击即可，首次启动会稍慢（要先解压内置资源）。

二、六个页面
01 图片浏览
  - 左侧显示图片浏览列表，双击文件夹进入，点「↑ 上一级」返回。
  - 列表每 5 秒自动刷新，ComfyUI 之类正在生成图片的目录会自动出现新图。
  - 搜索框按文件名过滤，支持中英文。
  - 选中图片或视频后在中间预览，右侧可一键「转到图片编辑 / 图片混淆 / 元数据清理」。
  - 视频下方有播放、暂停、可拖动的进度条和时间显示；空格键也能暂停/继续。

02 图片编辑
  - 选择图片或直接拖入、Ctrl+V 粘贴；左侧缩略图可切换多张图。
  - 工具：裁剪、打码（马赛克）、遮罩（高斯模糊）、贴纸。
  - 每张图的编辑历史独立，可撤销、重做、重置。
  - 滚轮缩放，中键平移，「适应」「100%」快速复位。

03 图片混淆
  - 选择图片或拖入、粘贴，可一次多张。
  - 选中图片后点「全部混淆」整批处理，或「全部解混淆」还原。
  - 「自动处理设置」可在导入时自动混淆 / 自动解混淆。
  - 处理完可单张下载、批量复制，或「下载 ZIP」打包导出。
  - 注意：PNG 保留原始像素可精确还原；其他格式会转成 JPEG（质量 95），是有损的。

04 去除元数据
  - 拖入或选择图片，支持单张、勾选、全部清理。
  - 输出统一为干净的 PNG：清除 EXIF、GPS、XMP、PNG 文本块，保留透明度。
  - 「打包文件夹」可自定义 ZIP 内层目录名，再点「批量下载」。

05 手机查看
  - 选择要共享的文件夹（默认跟随「设置」里的默认图片路径），设置端口后点「启动手机查看」。
  - 连接信息里会显示访问地址和一次性密码，可以直接选中复制，也可以点下面的「复制地址」「复制密码」。
  - 手机与电脑连同一个 Wi-Fi，手机浏览器打开地址，输入密码即可浏览图片和视频。
  - 授权一次后 30 天内免密，重启程序也不用再输。
  - 手机上点「关闭服务」可以直接停掉电脑端的服务。
  - 只面向局域网使用，没有 HTTPS，请不要在公共 Wi-Fi 上共享敏感目录。

06 设置
  - 「默认图片路径」是六个工具共用的起始目录：打开文件、保存、导出 ZIP 都从这里开始。
  - 「恢复系统默认」清空设置，回到「图片」文件夹。

三、文件都放哪里
程序不写注册表、不装服务，配置只有这几处：
  %LOCALAPPDATA%\PixelWorkspace\default-image-folder.txt   默认图片路径
  %LOCALAPPDATA%\PixelWorkspace\phone-view-devices.json    手机授权记录（只存 token 的哈希）
  %LOCALAPPDATA%\PixelWorkspace\browser-folder.txt         上次浏览的目录
删掉这个文件夹即恢复初始状态。

四、常见问题
  - 打不开 / 提示缺少文件：确认整个文件夹都在，或改用单文件版。
  - 某些 WebP 打不开：系统缺少对应解码器，程序会明确提示，不会假装成功。
  - 视频缩略图是播放图标：系统没有该格式的缩略图处理程序，mkv/webm 可安装 Icaros 之类的工具。
  - 去除元数据后文件变大：因为重新编码为 PNG，属正常现象。
  - 手机连不上：确认同一局域网、Windows 防火墙允许该程序，端口没被占用。
